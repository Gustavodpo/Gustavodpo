Meus projetos passam por desenvolvimento web e aprendizado de máquina aplicado, de uma ferramenta de produção de áudio no navegador a um estudo de dados cardiovasculares em Python.

## Projetos em destaque

| Projeto | O que você encontra | Tecnologias |
| --- | --- | --- |
| [Spot Studio](https://github.com/Gustavodpo/admin.spotstudio) | Ferramenta de produção de áudio para locuções e spots comerciais. Usa o Gemini para analisar roteiros, sugerir vozes e gerar áudio. O app inclui catálogo de vozes, presets, histórico de produção e exportação em WAV. | React, TypeScript, Vite, API do Gemini |
| [Classificação de Doenças Cardiovasculares](https://github.com/Gustavodpo/RandomForestCardioVascularDisease) | Projeto de classificação com Random Forest em Python. O repositório inclui a base de dados, o script de treinamento e visualizações de correlação entre variáveis, avaliação por matriz de confusão e interpretação com SHAP. | Python, scikit-learn, SHAP |
